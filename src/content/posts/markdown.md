# 一级标题

段落之间用空行分隔。

第二段。_斜体_、**粗体**和 `等宽字体`。无序列表如下：

- 第一个
- 第二个
- 第三个

注意 --- 不考虑星号 --- 实际文本
内容从第 4 列开始缩进。

> 块引用写法如下。
>
> 它们可以跨多个段落，
> 如果你喜欢的话。

使用 3 个破折号表示长破折号。使用 2 个破折号表示范围（例如，"全部内容
在第 12--14 章中"）。三个点 ... 将转换为省略号。
支持 Unicode。☺

## 二级标题

这是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再次注意，实际文本从第 4 列开始缩进（从左侧算起 4 个字符）。
这是一个代码示例：  

    # Let me re-iterate ...
    for i in 1 .. 10 { do-something(i) }

你可能已经猜到，这是缩进 4 个空格。顺便说一下，如果不喜欢缩进块，
你也可以使用分隔代码块：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这使得复制粘贴更容易）。你还可以选择性地标记
分隔块，让 Pandoc 进行语法高亮：

```python
import time
# Quick, count to ten!
for i in range(10):
    # (but not *too* quick)
    time.sleep(0.5)
    print i
```

### 三级标题

现在是一个嵌套列表：

1. 首先，准备这些食材：

    - 胡萝卜
    - 芹菜
    - 扁豆

2. 烧一些水。

3. 把所有东西倒进锅里，按照以下算法操作：

        find wooden spoon
        uncover pot
        stir
        cover pot
        balance wooden spoon precariously on pot handle
        wait 10 minutes
        goto first step (or shut off burner when done)

    不要碰到木勺，否则它会掉下来。

再次注意，文本总是以 4 空格缩进对齐（包括
上面继续第 3 项的最后一行）。

这是指向[一个网站](http://foo.bar)、[本地文档](local-doc.html)的链接，
以及[当前文档中的章节标题](#an-h2-header)。这里有一个脚注[^1]。

[^1]: 脚注文本放在这里。
